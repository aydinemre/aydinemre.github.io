Answer pattern#

  • State the model first: page size, PTE size, levels, TLB capacity and replacement, serial lookup, residency sl. 4, 13, 38.
  • Keep translation (where would the access go?) separate from protection (is the operation permitted?) Okuma §12; sl. 28.
  • Separate four questions: TLB hit/miss · valid (member of the address space) · resident · permitted sl. 35, 41, 68.
  • Label each arrow before calculating: entry address, entry contents, data address sl. 33, 48.
  • For an invalid reference: "There is no physical result to invent." Reject it explicitly sl. 28.
  • Check the bound before adding the base: 0 ≤ offset < limit, then base + offset sl. 10.

"X does not prove Y"#

Observation Does not prove Because
Two processes print the same pointer they share the data "A numerical address alone does not identify a unique physical byte" sl. 3, 31
Two different virtual addresses different bytes different virtual addresses can reach the same frame (0x1234 and 0x7234 → 0x9234) sl. 43
A TLB miss a page fault or a disk read a valid, resident mapping is recovered from the page table sl. 35, 67
A TLB hit permission the cached entry carries permissions: TLB=HIT PROTECTION sl. 64; Okuma §12
A frame number is available a write is allowed R/W/X and user/kernel checks can still reject sl. 41
Read-only for process A the frame is immutable B's read/write mapping may write it sl. 67
Shared writable memory safe updates "address translation does not prevent a data race" sl. 42
Physical byte 15000 (or 6700) exists the access is legal existence does not establish permission sl. 19; Okuma §3
Total free space ≥ request the request fits it needs one sufficiently large hole: 959 KiB free, largest 300, 426 fails sl. 12, 15
Best fit won this sequence best fit is always better an example outcome, not a proof Okuma §4
Paging no fragmentation removes contiguous placement; last-page internal fragmentation remains sl. 16, 29
Compaction no internal fragmentation it relocates allocations; unused space inside them stays sl. 17
A multilevel table less memory fully populated: 1025 pages > 1024 sl. 50
A 64-entry TLB covers 128 MiB no misses "nominal reach is not a guarantee of hits" sl. 56
Linux names five levels five lookups per miss unused levels are folded; large-page leaves end early sl. 57, 53
A /proc/PID/maps line residency or a frame number it reports a virtual range and permissions sl. 62, 63
Dynamic linking dynamic loading different questions: what is loaded vs how references are connected sl. 11
Intel 64 / x86-64 IA-64 IA-64 is a separate architecture sl. 58
PAE a 36-bit linear address the linear address stays 32 bits; physical becomes 36 Okuma §17

Formulas and steps#

What Formula Example
Split p = ⌊A/P⌋, d = A mod P; bits: p = m − n, d = n 0x1234, 4 KiB → p 1, d 0x234 sl. 21, 22, 71
Physical address PA = f × P + d (never f × P + A) frame 9 → 0x9234 sl. 25; Okuma §7
Page boundary adjacent virtual ≠ adjacent physical 0x0FFF → 0x3FFF, 0x1000 → 0x9000 sl. 27
Last-page waste pages = ⌈S/P⌉, waste = pages·P − S 72766 B, 2048 → 36 pages, 962 B sl. 29
Segment check d < limit[s], then base + d (0,430) → 1830; (1,400) → trap sl. 19
PTE address PTBR + VPN × PTE size 0x8000 + 1×8 = 0x8008; page 3 → 0x8018 sl. 33
EAT (lecture model) h(t+m) + (1−h)(t+2m) = t + (2−h)m t=1, m=100, h=0.95 → 106 ns; 201 − 100h sl. 38–39
EAT, k levels t + m + (1−h)·k·m k=2, h=0.95 → 111 ns sl. 51
OSC model ignores t: (2−h)m differs by exactly t; do not mix models Okuma §11
Linear table 2^(m−n) × PTE size 2^20 × 4 B = 4 MiB sl. 45
Level width log2(page size / PTE size) 4096/4 → 10 (10/10/12); 4096/8 → 9 (9/9/9/9/12) sl. 47; OSC ch9 sl. 65
Two-level walk outer = A >> 22, inner = (A >> 12) & 0x3FF 0x00403004 → 0x1004 → 0x500C → 0xA004 sl. 49
Sparse hierarchy (1 root + used leaves) × 4 KiB 3 regions → 16 KiB sl. 50
64-bit 2^52 entries; 42/10/12 outer = 2^44 B 3 levels outer = 2^34 B sl. 52, 73
TLB reach entries × page size 64 × 4 KiB = 256 KiB; 64 × 2 MiB = 128 MiB sl. 56
LRU trace a hit moves the page to MRU 0,1,0,2,1 with 2 entries → 1 hit / 4 misses = 20% sl. 36–37
Fit check final holes sum = initial − allocated 1700 − 1167 = 533 (best fit) sl. 14; Okuma §4

Sentences worth writing#

  • "Mapping existence and permitted access are separate checks." sl. 28
  • "A TLB miss is not a page fault." sl. 35
  • "A cached decision must not outlive the state on which it depends." Okuma §10
  • "Permissions belong to the relevant mapping." sl. 43
  • "Savings depend on sparsity." sl. 50
  • "Distinguish virtual-space validity, residency and cached translation." sl. 68
